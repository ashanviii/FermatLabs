# Reference breakdown: Linear for Agents

## Source and method

- Official Linear product reel, 32.63 seconds.
- Analyzed from sampled frames only: six overview sheets at 2 fps and seven 0.4-second cut strips.
- Audio and continuous motion were not reviewed, so timing observations below describe visible edits, not musical sync or animation smoothness.

## Director breakdown

The film opens with a quiet centered title over near-black, then reveals a dense product list below it. The title remains a stable orientation point while the product becomes the evidence. Interaction is shown through full-screen product states: select an agent, assign work, read the agent's response, enable an integration, and inspect the completed issue. The camera mostly stays still. Meaning comes from state changes, selection highlights and fast editorial replacement rather than decorative movement.

The pacing uses seven sharp changes at roughly 2.0, 5.0, 8.0, 12.0, 15.4, 17.5 and 24.1 seconds. The average interval is about 4.1 seconds, with a median of 3.2 seconds. Early sections are denser; the issue-detail proof receives the longest hold. The final eight seconds clear the product away, cycle a short family of category lines in the same position, restore the opening phrase and resolve on the Linear logo.

## Transition verbs

- **Focus:** an existing list softens, then the relevant rows return at full contrast.
- **Replace:** a menu or activity state cuts into the same product context without moving the whole composition.
- **Expand:** a selected agent or issue becomes the full subject of the frame.
- **Answer:** text accumulates inside an already-established response card.
- **Clear:** product UI disappears so one line can carry the close.
- **Cycle:** nouns replace each other in a fixed typographic position.
- **Resolve:** the title returns, then gives way to the logo.

## What Fermat borrows

- One dominant idea per shot.
- Product UI as evidence rather than decoration.
- A stable typographic position during the close.
- Mostly hard editorial changes with a few state transitions inside the product.
- Long enough holds for a real UI consequence to be read.

## What Fermat changes

- Uses Fermat's warm, daylight palette rather than Linear's near-black field.
- Opens with the group-chat problem before showing the product.
- Carries one rounded private-input object into the form so the transition explains privacy.
- Uses Fermat's real trip data and vocabulary; no imitation of Linear's colors, icons or interface.
